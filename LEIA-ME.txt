PUBLICAR NO NETLIFY
1. Extraia este ZIP num computador.
2. Entre em https://app.netlify.com/drop
3. Arraste a pasta Link_Direto_Connect_v3 para a página.
4. Aguarde o Netlify gerar o endereço HTTPS.
5. Abra o endereço no Safari do iPhone.
6. Partilhar > Adicionar ao Ecrã Principal.

IMPORTANTE
Esta versão ainda é protótipo: os dados são guardados localmente no navegador.
Para vários utilizadores reais conversarem entre si será necessário ligar uma base de dados/backend (ex.: Supabase ou Firebase).
