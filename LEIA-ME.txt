PASSO 1 — ATUALIZAR O SUPABASE
1. Abra o Supabase e entre em SQL Editor.
2. Clique em New query.
3. Abra ATUALIZAR_SUPABASE_COMPLETO.sql.
4. Copie todo o conteúdo, cole no SQL Editor e clique em Run.
5. O resultado correto é: Success. No rows returned.

PASSO 2 — PUBLICAR NO GITHUB
Envie todos os ficheiros desta pasta para a raiz do repositório e confirme as alterações.

PASSO 3 — TESTAR
1. Abra o endereço GitHub Pages numa janela anónima.
2. Crie duas contas com e-mails diferentes para testar entre dois aparelhos.
3. Confirme o e-mail se o Supabase solicitar.
4. Publique numa conta e envie uma proposta pela outra.
5. Aceite a proposta na primeira conta e abra a Sala de Negócio.
